# Cuentix

[Español](#español) · [English](#english)

## Español

**Cuentix** es una PWA para llevar tus ingresos y gastos, deuda, ahorros y balance con otras personas. Importás los movimientos de tu banco o billetera (Excel/CSV de BBVA y Fiwind), los categoriza y te muestra el mes a mes, la deuda de la tarjeta y cómo evolucionan tus ahorros. También podés formar grupos (hogares) para compartir gastos y subir fotos de tickets que se leen con IA.

> Estado: proyecto personal en producción en <https://cuentix.lulox.com.ar>. Funciona por invitación (lista de emails permitidos). Código abierto bajo AGPL.

### Stack

- Next.js (App Router, export estático) + TypeScript + Tailwind
- Cloudflare Workers (API + assets estáticos), D1 (SQLite) y R2 (tickets)
- Login con Google OAuth propio, sesiones en D1
- Workers AI para leer tickets y resúmenes

### Desarrollo

```bash
pnpm install
cp .env.example .env.local   # completá tus propias credenciales
pnpm test                    # tests (node:test + tsx)
pnpm build                   # export estático en ./out
pnpm run dev:lite            # Worker local con wrangler
```

Los datos de prueba (`fixtures/`) son **ficticios** y salen de `node scripts/make-mock-fixtures.mjs`. No subas extractos, tickets ni datos reales al repo.

### Configuración

- Secretos del Worker (nunca en git): `GOOGLE_CLIENT_SECRET`, `BETTER_AUTH_SECRET`, `CUENTIX_SYNC_SECRET`, etc. Ver `.env.example`.
- `REINTEGRO_PAYEES` (variable de runtime del Worker, nada más): nombres de quien adelanta alquiler/servicios, para no contar esos reintegros dos veces. Formato: `ANA+PEREZ,ANITA` (grupos separados por coma, tokens unidos con `+`). Vacío = desactivado.
- `OWN_ACCOUNT_IDS` (variable de runtime del Worker, nada más): CUITs, CBU/CVU o alias de tus propias cuentas, separados por coma. No commitees valores reales. Vacío = el config no aporta ids; los que aparecen en movimientos marcados como cuenta propia o cuenta tuya se suman solos.
- Google OAuth: origen `https://cuentix.lulox.com.ar`, redirect `https://cuentix.lulox.com.ar/api/auth/callback/google`.

### Deploy

```bash
pnpm exec wrangler d1 migrations apply cuentix --remote
pnpm build
pnpm exec wrangler deploy
```

Las integraciones (Agent API / MCP, sincronización con Serpix) están documentadas en [`docs/agent-api.md`](docs/agent-api.md).

## English

**Cuentix** is a PWA to track your income and expenses, debt, savings and shared balances. Import your bank or wallet movements (BBVA and Fiwind Excel/CSV), get them categorised automatically, and see month-by-month totals, card debt and how your savings evolve. You can also create groups (households) to split expenses and upload receipt photos that are read with AI.

> Status: personal project running in production at <https://cuentix.lulox.com.ar>. Invite-only (allow-listed emails).

### Stack

- Next.js (App Router, static export) + TypeScript + Tailwind
- Cloudflare Workers (API + static assets), D1 (SQLite) and R2 (receipts)
- Custom Google OAuth login, sessions stored in D1
- Workers AI to read receipts and statements

### Development

```bash
pnpm install
cp .env.example .env.local   # fill in your own credentials
pnpm test                    # tests (node:test + tsx)
pnpm build                   # static export into ./out
pnpm run dev:lite            # local Worker via wrangler
```

Test data under `fixtures/` is **fictional** and generated by `node scripts/make-mock-fixtures.mjs`. Never commit real statements, receipts or personal data.

### Configuration

- Worker secrets (never in git): `GOOGLE_CLIENT_SECRET`, `BETTER_AUTH_SECRET`, `CUENTIX_SYNC_SECRET`, etc. See `.env.example`.
- `REINTEGRO_PAYEES` (Worker runtime variable only): names of the person who fronts rent/utilities so those reimbursements are not double-counted. Format: `ANA+PEREZ,ANITA` (comma-separated groups, tokens joined with `+`). Empty = disabled.
- `OWN_ACCOUNT_IDS` (Worker runtime variable only): comma-separated CUITs, CBU/CVU numbers, or aliases of your own accounts. Never commit real values. Empty = config contributes no ids; ids found on rows marked as an own account are still added.
- Google OAuth: origin `https://cuentix.lulox.com.ar`, redirect `https://cuentix.lulox.com.ar/api/auth/callback/google`.

### Deploy

```bash
pnpm exec wrangler d1 migrations apply cuentix --remote
pnpm build
pnpm exec wrangler deploy
```

Integrations (Agent API / MCP, Serpix sync) are documented in [`docs/agent-api.md`](docs/agent-api.md).
